How to install

  1. Download the .vpk file of each campaign above. Don't unzip or rename it.
  2. Open your Left 4 Dead folder. In Steam: right-click Left 4 Dead → Manage → Browse local files. The usual place is C:\Program Files (x86)\Steam\steamapps\common\left 4 dead
  3. Go into left4dead\addons (create the addons folder if it isn't there).
  4. Put the .vpk files there, for example left 4 dead\left4dead\addons\darkblood.vpk
  5. Start (or restart) Left 4 Dead. The campaigns now show in the add-ons list and you can join the server on them.

Getting "Missing map" or kicked when the server changes map? That campaign isn't installed, or the file sits in the wrong folder. It must be left4dead\addons\, not left 4 dead\addons\. To try a map alone, open the console (~) and type map l4d_darkblood01_tanker.

Custom campaigns run only when an admin starts them. When the server is empty it goes back to the official campaigns, so you can always join without these files.
